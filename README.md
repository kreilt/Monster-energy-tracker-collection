# 🐲 Monster Energy — трекер вкусов

Веб-приложение для коллекционеров: чек-лист всех вкусов Monster Energy с
редкостью, описанием, фото банок и личным прогрессом, который синхронизируется
между устройствами.

🔗 **Живая версия:** https://monster-tracker-1ff07.web.app

> Неофициальный некоммерческий фан-проект. Не связан с Monster Energy® /
> Monster Beverage Corp. Все товарные знаки и изображения принадлежат их
> правообладателям.

---

## Возможности
- 140+ вкусов Monster, сгруппированных по линейкам
- Отметка «попробовал», поиск и фильтры (линейка / редкость / регион / статус)
- Уровни редкости, регион выпуска, статус (новинка / снят / лимитка / алкоголь)
- Вход через Google или e-mail-ссылку (passwordless)
- Облачная синхронизация прогресса и пользовательских фото между устройствами
- Замена фото банки на своё, экспорт/импорт прогресса (JSON)
- PWA: установка как приложение + офлайн-режим
- Тёмный неон-интерфейс

## Стек
- Чистый HTML / CSS / JavaScript (без сборщиков)
- **Firebase Auth** — вход (Google + email link)
- **Cloud Firestore** — данные пользователя + реалтайм-синхронизация + офлайн-кэш
- **Firebase Hosting** — хостинг
- **PWA** — Service Worker (офлайн), Web App Manifest (установка)

## Архитектура
- UI работает через единый интерфейс `store`; есть две реализации:
  `LocalStore` (localStorage) и `CloudStore` (Firestore) — переключение без
  изменения UI (`app.js` ↔ `cloud.js`).
- Данные пользователя: `users/{uid}` = `{ tried[], images{} }`.
- Security Rules: каждый видит только свой документ.

## Структура
```
app.html            экран входа + кабинет
app.js              логика UI + LocalStore
cloud.js            Firebase Auth + Firestore (CloudStore)
firebase-config.js  публичная конфигурация Firebase
flavors-data.js     база вкусов (единый источник данных)
service-worker.js   офлайн-кэш (PWA)
manifest.json       манифест приложения
firestore.rules     правила доступа Firestore
icons/              иконки приложения
images/             фото банок (в репозиторий не входят — см. ниже)
docs/               ТЗ, прогресс, инструкции
```

## Про фото
⚠️ **Фотографии банок намеренно НЕ включены в этот репозиторий** — чтобы не
нарушать авторские права их владельцев. В коде фото нет; приложение при
отсутствии файла показывает аккуратный плейсхолдер с названием вкуса.

📸 **Посмотреть проект с фотографиями** можно на живой версии:
**https://monster-tracker-1ff07.web.app**

Каталог `images/` наполняется локально (например, скриптом
`download-images.ps1`) и в систему контроля версий не попадает.

## Запуск локально
```bash
# любой статический сервер, например:
py -m http.server 8080
# затем открыть http://localhost:8080/app.html
```
Для облачного режима нужен свой проект Firebase (Auth + Firestore) и свои ключи
в `firebase-config.js`.

## Деплой
```bash
firebase deploy --only hosting
```
