Сюда складываются картинки вкусов — по одной на вкус, имя файла = "slug".jpg
(slug генерируется автоматически из названия).

Как заполнить автоматически:
  запусти ..\download-images.ps1  (нужен интернет один раз).

Хочешь поставить своё фото для конкретного вкуса:
  положи сюда файл с правильным именем, например:
     monster-energy-original.jpg
     juice-monster-mango-loco.jpg
  (точное имя slug для каждого вкуса печатает download-images.ps1 в конце,
   в списке "Not found", либо смотри в image-manifest.example.json).

Поддерживаются .jpg (можно положить png/webp, но переименуй в .jpg —
браузер всё равно покажет).
